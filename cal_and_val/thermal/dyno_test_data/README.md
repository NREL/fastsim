To download dyno data, go to https://www.anl.gov/taps/downloadable-dynamometer-database. 
Once the data is downloaded, move the whole vehicle data file into the dyno_test_data folder.  
Note: only data from the "Extended Datasets" folder is needed. Alternatively, you can just
download this folder, and create a folder in the dyno_test_data with the vehicle name to house the
Extended Datasets downloaded folder in.
